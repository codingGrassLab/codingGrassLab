## Research Areas & Analytical Methods

| Research Area | Methods & Technologies |
|---|---|
| **Transcriptomics & Single-Cell Analysis** | Bulk RNA-seq, microarrays, GEO/TCGA, differential expression (DESeq2, limma), scRNA-seq clustering, batch integration and trajectory analysis (Seurat, Harmony) |
| **Epigenomics & Chromatin Biology** | ATAC-seq, ChIP-seq, peak calling (MACS2), differential binding (DiffBind), motif enrichment (HOMER, MEME), chromatin accessibility and transcriptomic integration |
| **Proteomics & Systems Biology** | Mass-spectrometry proteomics, differential protein abundance, gene co-expression networks (WGCNA), PPI analysis (STRING, Cytoscape, CytoHubba, CytoNCA) |
| **Immunoinformatics** | Immune-cell composition estimation and deconvolution (CIBERSORTx, xCell), disease-associated immune signatures |
| **Structural Bioinformatics** | Protein structure analysis, molecular docking (AutoDock Vina), protein–ligand interactions, molecular dynamics (GROMACS), RMSD, RMSF, Rg, SASA and MM-PBSA |
| **Evolutionary & Comparative Genomics** | Sequence alignment (MAFFT, MUSCLE), phylogenetics (IQ-TREE, MEGA), selection pressure analysis (dN/dS), SNP and variant analysis |
| **Machine Learning & Bio-Automation** | Machine Learning Models, biomarker feature selection, Python/Bash pipelines and high-throughput primer design |
